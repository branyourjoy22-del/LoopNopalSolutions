# Sitio estático de Loop Nopal Solutions

El sitio y las simulaciones utilizan únicamente HTML y CSS.

## Abrir el proyecto

Abre `index.html` directamente en un navegador. No requiere instalación,
compilación, servidor ni dependencias de Node.

## Archivos principales

```text
index.html
styles.css
public/qro-aerea-cristian-gonzalez.jpg
public/loop-nopal-logo-transparent.png
simulaciones/
  simulaciones.css
  v1.html
  v2.html
  v4.html
```

## Alcance de las simulaciones

Las animaciones son deterministas y los resultados numéricos son demostrativos.
HTML y CSS no calculan llegadas aleatorias, colas ni métricas en tiempo real.
Antes de usar los valores para decisiones operativas se requieren aforos viales
y validación técnica.
